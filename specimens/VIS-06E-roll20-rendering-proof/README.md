# VIS-06E — Roll20 Rendering Proof

Purpose: prove that the approved ornate visual language can be rendered with reusable assets and Roll20-compatible HTML/CSS without flattening the character sheet into one image.

The proof should contain:

- Cinematic race-reactive header.
- Separate transparent class-overlay layer.
- Display-only Name / Race / Class in header.
- Level / Floor context.
- Seven-tab navigation.
- One ornate reusable panel frame.
- Compact 72–88px stat tiles using the crawler's actual five-stat model.
- One real form input and focus state.
- One repeating-style data row.
- One status/provenance badge.
- Existing 10-slot Health Bar treatment shown only in working content, never in the header.
- Representative chat-template card.

## Acceptance criteria

- Ornate border treatment survives without interfering with live controls.
- No mechanics are invented.
- Working text remains readable over all approved artwork.
- Race and class layers can be swapped independently.
- Shared chrome is reusable across multiple panel sizes.
- Narrower layouts remain usable even if banner cropping becomes more aggressive.

This specimen is visual proof only and must not be treated as a production release branch.
