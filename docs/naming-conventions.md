# Naming Conventions

Use lowercase kebab-case.

## Banners
- `race-tigran-header.webp`
- `race-human-header.webp`
- `race-neutral-header.webp`

## Class overlays
Use theme families rather than every individual class when possible.
- `class-barbarian-claw-impact.png`
- `class-mage-arcane-glyphs.png`
- `class-rogue-shadow-cuts.png`

## Chrome
- `chrome-panel-corner-tl.png`
- `chrome-panel-corner-tr.png`
- `chrome-divider-bronze-horizontal.png`

## Badges
- `badge-club-desperado.png`
- `badge-status-equipped.svg`

## Versioning
Do not put production revision numbers in visual asset filenames. Visual milestones use VIS-xx in documentation, not in reusable asset filenames.
