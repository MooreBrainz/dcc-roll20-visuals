# Visual Handoff

Before any asset is promoted into production engineering, provide:

1. Asset path and purpose.
2. Source and rendered dimensions.
3. File format and approximate size.
4. CSS placement behavior: cover / contain / repeat / stretch.
5. Safe text area or crop notes.
6. Required UI state, if any.
7. Fallback behavior.
8. Relationship to current HTML/worker systems.
9. Accessibility/contrast notes.
10. Visual milestone approval reference.

Visual approval does not equal production promotion.
