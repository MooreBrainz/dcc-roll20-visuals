# DR1 R25 — subtle neutral field-edge ornaments

TEST-ONLY graphics for character header identity fields. Two transparent WebP fragments (`field-edge-left.webp`, `field-edge-right.webp`), 28 × 76 pixels, 186 bytes apiece. They provide tiny neutral etched edges and corner highlights; the actual field surface, text, editing, layout and focus states remain CSS/HTML.

R25 intentionally supersedes the colourful R24 "machined plates" and uses one restrained graphite/silver visual treatment for Name/Crawler No., Race, Class, Level, Floor, and the Entity selector. Existing race/class banner and DCC logo are not changed.

Use immutable commit-pinned asset URLs. No production promotion until R25 passes hands-on Roll20 visual and mechanical tests.
