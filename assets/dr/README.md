# DR visual assets

**DR# R#** is the experimental character-sheet visual design series. This directory is intentionally separate from existing `assets/headers/` race/class art, `assets/brand/` logo files, and the independent Action Tracker.

Visual direction: **hybrid** — lightweight pre-rendered industrial chrome, with all information, controls, resize behavior, and state handled by actual Roll20 HTML/CSS.

Current prototypes:
- [DR1 R2 Combat Status artwork](chrome/combat-status/README.md) — first test-only sliced header.

All DR art is provisional until separately approved in live Roll20. Never treat publication to this asset repository as promotion to the live character sheet.
