# Roll20 Header Assets

Layer order (bottom to top):

1. `races/<race>/background.webp` — full-width, low-contrast pattern behind fields.
2. `races/<race>/character.webp` — transparent portrait in the right-side art zone.
3. `classes/<class>/overlay.webp` — optional transparent atmospheric overlay above race images, below interactive fields (future).
4. Roll20 sheet header UI — text, buttons, and status rails.

Only use assets approved for a race. Unknown/unassigned races must use the unchanged neutral sheet header. Keep mechanical field attributes and the existing worker independent of art.
