# Character-sheet artwork

All active character-sheet artwork is kept under stable published paths:

- `headers/races/` — 30 race background/character pairs.
- `headers/classes/` — 51 class overlays.
- `brand/dcc-ttrpg-header-logo.webp` — existing DCC TTRPG logo.
- `banners/class-overlays/class-berserker-1496x144.png` — retained historical class banner.

## Asset rules

Use image files for decorative layers and CSS/HTML for layout, live text and controls. Never bake game values, editable labels, or state into artwork. Optimize and reuse assets; validate cropping and text contrast at compact Roll20 widths. Keep artwork links stable and pin approved production URLs to immutable commits when possible.

Abandoned VIS-series art and prototype scaffolding have been removed from the active tree. Future design packages use the **DR# R#** naming series.
