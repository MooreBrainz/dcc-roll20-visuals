# Asset library

This directory contains reusable visual assets only. Do not encode game state or mechanics into artwork.

## Rules

- Prefer WebP for opaque photographic/painted banners.
- Prefer transparent PNG/WebP for overlays, chrome pieces, and emblems.
- Race art is the primary header identity.
- Class overlays are secondary and should remain visually subordinate.
- Reuse chrome across the sheet rather than painting unique borders into every component.
- Keep a safe center/right text zone in banner artwork so live HTML remains readable.
- Never bake editable text, values, Health, Mana, or controls into an image.
